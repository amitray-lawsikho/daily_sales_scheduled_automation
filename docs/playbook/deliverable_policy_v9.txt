Deliverables (3 files by default)

Default every run — THREE PDFs:

MTD Report [Mon] 1-N - Team Uzair.pdf
MTD Report [Mon] 1-N - Sales Teams.pdf

That is the whole delivery. When the user says "run MTD analysis till [date]" (or any equivalent trigger) with no further qualification, produce all three segment PDFs, send them, and give the in-chat brief. Do not produce or send any xlsx unless asked.

Each PDF follows pdf_design_spec.md in full — segment pages 1-3 plus one deep-dive page per team in that segment. Segment 2 (Sales Teams) still repeats Team Uzair's team pages so every PDF stands alone.

revenue_history.csv is still rebuilt and saved back to the project on every run. It is not a delivered file and is not sent to chat unless asked for.

The xlsx set is on request only, e.g. "include the xlsx", "give me all files". Asking for the full set produces the original 7: these three PDFs, three xlsx (same three segments), plus revenue_history.csv.

Partial requests still work as before: "[segment] only" produces just that segment's PDF (and its xlsx only if the xlsx set was also requested).
